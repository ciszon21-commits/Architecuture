# 知識管理政策

## 單一編輯來源

主題與搜尋詞編輯knowledge/exam/scope.json；四款表列尺寸編輯knowledge/rules/stairs.json；核對紀錄編輯knowledge/sources/registry.json。建置輸出不手改。資料欄位與模板文字都納入Git比較。

新增規則時，先建立來源識別碼與條項款目，再建立教學內容。sources紀錄actor、查閱日、來源整編截止日、核對範圍、來源狀態及專業審核狀態。查閱日不能推定為條文修正日或施行日。

## 查證與審核

source_checked只代表記錄中的特定範圍完成來源核對。professional_review=pending不能改成approved，除非有實際審核人及證據。考綱索引片段的核對不得冒充原始附件全文核對。

目前資料是本次現行頁面查閱的原型輸入，還沒有完整歷史版本庫。後續改版採新的版本ID，舊條文、歷屆答案與教材修訂版保留。

## 修法處理

建立新來源紀錄 → 比較條項款目 → 找出受影響規則、模板文字、圖解與題解 → 標記待重審 → 修正測試 → 專業審核 → 發布。不能只有更新數字而漏掉例外、施行日或題解。

## 知識缺口

gaps保留未解決問題；更新狀態時寫出查過什麼、尚缺什麼與下一個官方來源。考題頻率沒有統計就不標常考；沒有官方試題就明示自編。

## 證據及跨電腦

來源快照和個人資料不進Git。選定的自製截圖可放docs/evidence/，記錄用途與驗證範圍。大型證據走經授權的附件儲存；交接文件放相對索引、檔案雜湊與回執，不放密鑰或電腦專屬路徑。
