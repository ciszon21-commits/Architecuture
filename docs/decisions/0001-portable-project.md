# ADR 0001：獨立儲存庫與可重建原型

日期：2026-10-20。狀態：採用於目前原型；正式框架選擇另立決策。

## 背景

使用者要求跨電腦開發，指定獨立GitHub儲存庫。先前成果位於聊天暫存產物位置，不適合作為長期原始碼來源。

## 決策

保留指定儲存庫名稱Architecuture，建立獨立checkout，不嵌入HJPLUS知識庫。將HTML拆為可建置範本及知識資料，以Node內建功能重建自足網頁。

Node版本與鎖檔進Git；dist、node_modules、本機資料和憑證排除。main透過功能分支與PR接收變更；每台電腦各自clone。

知識來源核對、專業審核與程式測試分開追蹤。來源與數值的待辦狀態不能在搬移時消失。

## 影響

另一台電腦不需要原聊天路徑或既有KB即可重建。初期沒有第三方執行依賴。正式Next.js遷移、資料庫與帳號同步仍是後續工程，不把原型包裝成已完成的正式平台。
